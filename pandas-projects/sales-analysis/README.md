# Sales Analysis Project

## Objective
Analyze the Superstore dataset using Pandas to identify sales trends, top-performing products, regions, categories, and states.

## Questions Answered

- What is the total sales revenue?
- What are the top 10 products by sales?
- Which regions generate the most revenue?
- Which categories perform best?
- Which states generate the highest sales?

## Tools Used

- Python
- Pandas
- VS Code


## Skills Demonstrated

- Data Cleaning
- Data Aggregation
- GroupBy Operations
- Sorting and Ranking
- Business Analytics
